# Evaluación y mejora del rendimiento web

## Objetivo

Evaluar la experiencia de carga de las vistas representativas de Clínica Internacional, identificar oportunidades de mejora mediante Lighthouse y PageSpeed Insights, y contrastar los resultados antes y después de aplicar cambios al sistema.

## Metodología

La versión inicial se identifica mediante el tag `v1.0.0`, asociado al commit `8d0fd85a630ac0633c692c397d5dd2342d73460c`. La versión optimizada se identificará con una versión posterior aprobada, conservando ambas referencias para reproducir la evaluación.

Se analizarán las páginas públicas con PageSpeed Insights y las vistas privadas con Lighthouse, manteniendo la sesión de una cuenta de prueba. Se comprobará que cada auditoría mida la URL y contenido esperados. Las pruebas se ejecutarán secuencialmente, en condiciones equivalentes, con tres repeticiones por página y perfil de dispositivo. El resultado representativo será la mediana; los reportes originales y las capturas se conservarán como evidencias.

Se registrarán las puntuaciones de rendimiento, accesibilidad, buenas prácticas y SEO, junto con FCP, LCP, TBT, CLS y Speed Index. El arranque tras inactividad de Railway se documentará por separado. Los resultados corresponden a pruebas de laboratorio y no determinan por sí solos la capacidad de usuarios simultáneos de la aplicación.
